# PrompTugal.news Weather

**Domain:** https://weather.promptugal.news

**Focus:** Weather and civil protection for Portugal, place by place: IPMA warnings and forecasts, fire risk, storms, sea state, UV, with visualisations; the Storm Charles site becomes its first archived event.

Part of [PrompTugal.news](https://promptugal.news/) (Portugal, town by town). It reads its raw data from [data.promptugal.news](https://data.promptugal.news/).

## Status
First version (17 November 2026): the Algarve's 17 places with IPMA warnings, the nearest station, five-day forecasts, fire risk, sea and UV; a map of warnings and fire risk; the district capitals listed as next; the Storm Charles archive; what to do and who to follow; three front-page designs at `/design/`. What exists is in `REALITY.md`. Not a warning service.

## Build
```
node scripts/sync-data.mjs   # copy data/by-place/now/*.json and the map files from PrompTugal__News__Website into data/
node scripts/build.mjs       # src/ + data/ + content/ -> _site/ (pages, markdown twins, llms.txt, sitemap.xml)
node scripts/validate.mjs    # the gate: must print OK
node scripts/leak-scan.mjs   # must print OK before every commit
```
Node 18+, no dependencies. Pages are generated by `scripts/site/generate.mjs` (helpers in `scripts/site/lib.mjs`, design variations in `scripts/site/design/`); hand-written pages are `content/*.md`; storms are `data/storms/<id>.json`. The site runs no collector: the data is IPMA's, read by the Website repository's collector, and moves to data.promptugal.news's APIs when they exist.

## How it works
- `dev` is the default branch. Every push to `dev` builds the site from `src/` and deploys it to GitHub Pages (`.github/workflows/pages.yml`), with the version at https://weather.promptugal.news/version.json.
- `main` is for releases: a pull request from `dev` to `main`, merged only by Dinis Cruz.
- No secrets in this repository. `.credentials/` and `.sg-send/` are ignored by git.
